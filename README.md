# EPL-Analysis
A collection of Premier League data analyses using complete 2025/26 data and incoming data from 2026/27. 

This project was created for personal enjoyment and exploration of Premier League and Fantasy Premier League data.

## Note
All data came from the publicly available [FPL-Core-Insights](https://github.com/olbauday/FPL-Core-Insights)
repository that updates regularly

Insights and visualizations are viewable.

## Installation 

1. Clone this repo (e.g., `git clone https://github.com/bbranduhn/EPL-Insights.git`)'

2. Create a `.env` file in the project directory and add the path to the data repository
```python
DATA_REPO_PATH = FOLDER_PATH_HERE
```

Now you're able to run any of the codebases
